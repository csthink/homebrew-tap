# homebrew-tap

Homebrew tap for [llmkeys](https://github.com/csthink/llmkeys) — a macOS credential &
config manager for LLM providers (keys via keychain/Bitwarden, config stores only references).

## Install

```sh
brew install csthink/tap/llmkeys
```

That's shorthand for:

```sh
brew tap csthink/tap
brew install llmkeys
```

## Upgrade

```sh
brew upgrade llmkeys
```
